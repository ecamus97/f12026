# Logos de los equipos

Coloca aquí el logo de cada escudería con el id del equipo como nombre de archivo
(`.png`, `.svg` o `.webp`; se usa el primero que exista). El juego lo muestra junto al auto, en la barra lateral,
en la selección de equipo y en las noticias. Si no hay archivo, se dibuja un escudo
con los colores del equipo.

| Equipo | Archivo |
| --- | --- |
| McLaren | `mclaren.svg` |
| Mercedes | `mercedes.svg` |
| Ferrari | `ferrari.svg` |
| Red Bull | `redbull.svg` |
| Williams | `williams.svg` |
| Aston Martin | `aston-martin.svg` |
| Racing Bulls | `racing-bulls.svg` |
| Haas | `haas.svg` |
| Alpine | `alpine.svg` |
| Audi | `audi.svg` |
| Cadillac | `cadillac.svg` |

Recomendado: fondo transparente, formato cuadrado, al menos 256×256 px, y colores claros
(el juego tiene fondo oscuro: las partes negras no se ven).
